# こつこつ

貯金の目標と、貯まっていく様子がひと目でわかる自分用アプリ（PWA、スマホ向け）。

## できること
- 目標を作る：貯金／積み立て（投資）、名前・目標金額・期限（なくてもよい）・アイコン・色
- 入金・出金の記録：右下の「＋」から。金額・目標・日付・メモ。「+1000」などのボタンで足せる
- 定期積立：目標ごとに「毎月◯日に◯円」。その日を過ぎてアプリを開くと自動で記録
- 積み立て（投資）：入れた額（元本）と評価額を分けて表示。評価額は証券会社のアプリを見て手で更新。更新後に入れた額は評価額に足して表示
- 目標ごとの進み具合：達成率のバー、のこり、期限まであと何日、月あたり必要な額、今のペース（直近3か月）での達成見込み
- 合計：いまの貯金と今月の増減
- AIに相談：状況のまとめと質問をコピーして Claude を開く（貼り付けて送る）。一般的な考え方を聞く文面にしてある
- 出費：Apple Pay の支払いをショートカットでファイルに書き足し、「出費」→「取り込む」で読み込む（同じ行は二度入らない）。店名から自動で分類し、直した分類は次から同じ店に使う。現金などは「＋」で手入力
- グラフ：月末の貯金（12か月、目標ごとの積み上げ）と月ごとの増減
- 達成・半分到達でお知らせ。達成した目標は「しまう」でホームの下へ
- バックアップ：データをコピー／貼り付けて読み込む、CSV で保存
- ダーク表示、電波がなくても開ける（sw.js）

## データ
端末の中（localStorage）だけに保存する。サーバーには送らない。
iPhone では「ホーム画面に追加」したアプリと Safari で保存場所が別になるので、ふだんはホーム画面のアイコンから開く。

## 置き方
GitHub Pages などの HTTPS のサーバーにこのフォルダの中身を置き、iPhone の Safari で開いて 共有 →「ホーム画面に追加」。
