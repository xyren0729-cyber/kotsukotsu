# こつこつ

貯金の目標と出費がひと目でわかる自分用アプリ（PWA、スマホ向け）。
サイト：https://xyren0729-cyber.github.io/kotsukotsu/

## できること

### 貯金
- 目標：貯金／積み立て（投資）。ひな形（52週チャレンジ・500円玉貯金・生活防衛資金・毎月1万円）からも作れる
- 入金・出金の記録、定期積立（毎月◯日に◯円を自動で記録）
- 積み立て：元本と評価額を分けて表示。NISA の口座にすると、今年の投資額（つみたて投資枠 年120万円）と生涯枠（1,800万円）の目安を表示
- 進み具合：達成率、のこり、あと何日、月あたり必要な額、今のペースでの達成見込み、連続でプラスだった月数

### やる気を続ける
- お祝い：目標の達成、25%・50%・75%、合計がきりのいい額（100万まで10万ごと、500万まで50万ごと、その先100万ごと）を超えたとき、新しい実績をとったときに紙吹雪。それ以外の入金は「+¥◯！ 目標◯%・あと◯円 今月◯回目」
- 実績（🏅）：20個。合計額、連続プラス、記録回数、目標達成、投資デビュー、予算どおり、出費ゼロの日、ガマン貯金、口座チェック
- 未来の自分：直近3か月の平均ペースで 1年後・5年後・10年後の貯金
- ガマン貯金（🙅）：買うのをやめた分（コーヒー・コンビニなど）をワンタップで貯金に。今月の回数と合計を表示
- 出費ゼロの日：今月、Apple Pay の記録がない日を数える
- 目標の「なぜ貯める？」の一言をカードに表示
- 連続記録を守る：20日を過ぎて今月がまだプラスでないとお知らせ

### 自動化・衝動買い対策・見える化
- 先取り貯金を自動に（設定）：やり方（送金元から自動送金／貯金用口座へ引き寄せ／証券口座で積立）、口座（最初は 三菱UFJ → ゆうちょ）、額、日、目標を選ぶと、やることのチェックリストが出て、目標の定期積立も入る。お金を動かす設定自体は銀行・証券会社で行う
- 銀行の明細 CSV：日付・支払い・預かり・残高の列を見出しから探す（Shift_JIS/UTF-8、西暦・和暦・8桁の日付）。カード・ATM は最初は外す。最新の残高で口座を更新（手で入れた方が新しければそのまま）
- 欲しいものリスト：30日待って「まだ欲しい？」。やめたらガマン貯金へ
- 時給換算：手取りの時給を入れると、出費・欲しいものを「約◯時間ぶん」で表示
- 1年カレンダー：貯金した日・出費ゼロの日をマス目で（グラフ）
- 月の通信簿：5項目（プラス・先月以上・予算内・ゼロの日5日・先取り）で A〜E（グラフ、月初のお知らせ）
- 予定ライン：期限のある目標で、まっすぐ貯めた場合の今日の額をバーに線で。先行・遅れを表示
- 目標の写真：横640px の JPEG にして端末に保存
- 臨時収入の振り分け：割合で目標ごとに記録（割合は次回も使う）
- ウィジェット：`widget.js`（Scriptable）。iCloud Drive の Scriptable フォルダの最新のバックアップを読む

### 口座の残高
- 銀行口座（最初はゆうちょ銀行・三菱UFJ銀行）の残高を、銀行アプリを見て手で入れる。前回比、合計、「目標に入れた貯金を除いた額」を表示
- 「残高を入れる」で全口座を1画面で入力（Enter で次の口座へ）
- 背面タップ：銀行アプリの画面でショートカットがスクショ→文字を読み、`kotsukotsu-pay.txt` に「日時 ⇥ 残高 ⇥ 画面の文字」を書き足す。取り込むと口座（ゆうちょ／三菱UFJ などの文字）と金額（「残高」の近くの円・¥）を推し量り、確認画面で直して保存
- 前回から30日たつとホームでお知らせ。残高の記録は残り、AI 相談のまとめにも入る
- 銀行は個人向けに残高を読む窓口がないため自動では読まない（ID・パスワードを使う読み取りはしない）

### 出費
- Apple Pay の支払いをショートカットでファイルに書き足し、「取り込む」で読み込む（同じ行は二度入らない）。店名から自動で分類し、直した分類は次から同じ店に使う
- 予算：毎月の合計と分類ごと。残り、1日あたり使える額、使いすぎは色で知らせる。月末5日は「余りを貯金へ」
- 毎月の支払い：同じ店で月1回・ほぼ同じ金額が2か月以上続くもの（サブスクなど）を自動で見つけ、年額も表示
- 固定費：家賃などを登録すると毎月自動で出費に記録
- ひとこと評価：出費に「よかった／ムダだった」

### お知らせ（起きたときだけホームの上に1行、×で今月は出さない）
- 給料日の先取り貯金、月初のふり返り、評価額の更新（30日以上前）、月末の AI 相談、バックアップ（30日以上前）

### AIに相談
- 状況のまとめ（貯金・目標・出費・予算・毎月の支払い・ムダだった出費・前回の答えの要点）と質問をコピーして Claude を開く
- Claude の答えを貼り付けて残すと、次の相談に要点が入る

### グラフ
- 月末の貯金（12か月）、月ごとの増減、生活防衛資金の目安（ふだんの出費×3〜6か月）、積立シミュレーター

### そのほか
- 金額を隠す表示（右上の 👁）、ダーク表示、電波がなくても開ける
- バックアップ：ファイルに保存（iPhone は「"ファイル"に保存」）／ファイルから戻す、コピー・貼り付け、CSV
- `#add` `#spend` で入力画面を直接開く（Android はアイコン長押しのメニュー）

## データ
端末の中（localStorage）だけに保存する。サーバーには送らない。
iPhone では「ホーム画面に追加」したアプリと Safari で保存場所が別なので、ふだんはホーム画面のアイコンから開く。
